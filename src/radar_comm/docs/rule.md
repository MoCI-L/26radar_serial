## 一、通信协议

### 1. 数据帧结构

| 字段         | 长度     | 说明                            |
|--------------|----------|---------------------------------|
| frame_header | 5 字节   | 帧头，包含起始符、长度、序号、CRC8 |
| cmd_id       | 2 字节   | 命令码，标识数据类型            |
| data         | n 字节   | 数据段，长度由 data_length 指定  |
| frame_tail   | 2 字节   | CRC16 校验，整包校验             |

### 2. 帧头格式（frame_header）

| 字段        | 偏移 | 长度 | 描述                             |
|-------------|------|------|----------------------------------|
| SOF         | 0    | 1    | 起始字节，固定为 0xA5            |
| data_length | 1    | 2    | data 字段长度（字节）            |
| seq         | 3    | 1    | 包序号                           |
| CRC8        | 4    | 1    | 帧头 CRC8 校验                   |

### 3. 命令码 ID 列表

| 命令码 | 数据段长度 | 描述                         | 发送方 → 接收方 | 所属链路       |
|--------|------------|------------------------------|------------------|----------------|
| 0x0A01 | 24         | 对方机器人位置坐标           | 发射源 → 雷达    | 雷达无线链路   |
| 0x0A02 | 12         | 对方机器人血量信息           | 发射源 → 雷达    | 雷达无线链路   |
| 0x0A03 | 10         | 对方机器人剩余发弹量         | 发射源 → 雷达    | 雷达无线链路   |
| 0x0A04 | 8          | 对方队伍宏观状态信息         | 发射源 → 雷达    | 雷达无线链路   |
| 0x0A05 | 36         | 对方机器人当前增益效果       | 发射源 → 雷达    | 雷达无线链路   |
| 0x0A06 | 6          | 对方干扰波密钥               | 发射源 → 雷达    | 雷达无线链路   |

> 所有命令码的上报频率上限均为 10Hz。

## 二、无线电参数

### 调制方式
- **调制类型**：2-GFSK，即二进制高斯频移键控
- **FSK 映射关系**：
	0→-1，1→+1；

### 参数关系
- **Interpolation（插值倍数）** = SPS = Sample Rate / Symbol Rate
- **Gain（增益）** = SPS
- **Sample Rate（采样率）** = 2 MHz（固定）
- **Symbol Rate（符号率）** = 波特率
- **BT（高斯滤波器带宽时间积）** = 0.35
- **Sensitivity（调频灵敏度）** = 2 * pi * Δf / Sample Rate（单位：rad/sample）
- **频偏Δf **  = signal_bandwidth / 2 - Sample Rate / SPS
- **带宽 B ** = signal_bandwidth（PlutoSDR RF 滤波器带宽）

## 三、信息波与干扰波

### 信息波（广播源）
包含以下对方信息：
- 各机器人位置
- 各机器人血量
- 各机器人剩余发弹量
- 各机器人当前增益
- 队伍剩余经济
- 队伍总经济
- 对方各增益点占领状态

### 干扰波（干扰源）
- 不含具体信息，仅包含一个 **6位数字字母组合的密钥**
- 开局密钥为随机值
- 开局时干扰波默认均为 **一级难度**
- 雷达可解析该密钥并发送给赛事引擎服务器
- 若解析成功，对方干扰波难度提升 **1 级**
- 若对方干扰波难度高于己方，则对方雷达对己方机器人即使准确标记，也不会产生易伤或积累“双倍易伤”进度

## 四、频率偏移计算（补充信息）

### 公式
- **带宽**：B = 2 × (Δf + Bstop)
- **频偏**：Δf = Symbol Rate
- **截止带宽**：Bstop = 0.02 MHz

### 示例（红方广播源）
- 中心频率：433.2 MHz
- 符号速率：250 kHz
- 映射关系：
  - 00 → -3 → Δf = -250 kHz
  - 01 → -1 → Δf = -187.5 kHz
  - 10 → 1  → Δf = 187.5 kHz
  - 11 → 3  → Δf = 250 kHz
